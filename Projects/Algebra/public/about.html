Project Title: Algebra – User-Based Calculator with History Tracking

Description

Algebra is a web-based application that combines a scientific calculator with a secure user login system. Built using HTML, CSS, JavaScript for the frontend and Node.js with Express for the backend, it enables users to perform complex calculations while maintaining a personalized history of each session.

The app uses express-session to manage authenticated user sessions and stores user credentials and individual calculation histories in JSON files, eliminating the need for a database. After logging in, users can access a responsive calculator interface, and every calculation they perform is recorded and displayed in their personal history section.

Key Features

  • User signup and login system
  • Session-based authentication using express-session
  • Scientific calculator built with JavaScript
  • Personalized calculation history saved per user
  • Data stored in structured JSON files (no database required)
  • Clean and responsive UI using HTML and CSS
